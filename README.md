# DevAI Studio — AI Website & App Builder

نسخة أولى قابلة للتشغيل لمنصة تطوير مواقع بمساعدة الذكاء الاصطناعي. الواجهة عربية RTL ومتجاوبة، وتضم محرر Monaco، مستكشف ملفات، معاينة HTML/CSS/JavaScript معزولة، محادثة API من جهة الخادم، استيراد ZIP وتصديره، وحفظًا محليًا تلقائيًا للمشاريع.

> **حدود النسخة الحالية:** حفظ المشاريع محلي على المتصفح. ملف Firebase يحتوي تهيئة اختيارية فقط ولا ينفّذ بعد تسجيل الدخول أو مزامنة Firestore. تكامل GitHub وبيئة بناء وتشغيل React/Next.js غير مفعّلين بعد. لا تضع بيانات سرية داخل ملفات الواجهة. لا يُدّعى اتصال أي خدمة ما لم تُهيّأ وتُختبر فعليًا.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- مفتاح API لمزود النموذج عند استخدام محادثة AI

## التثبيت والتشغيل

```bash
npm install
cp .env.example .env.local
```

افتح `.env.local` وأضف مفتاح API على جهازك أو بيئة الاستضافة:

```env
OPENAI_API_KEY=ضع_مفتاحك_هنا
OPENAI_MODEL=gpt-4.1-mini
```

ثم شغّل:

```bash
npm run dev
```

افتح `http://localhost:3000`.

إذا لم تضف المفتاح، ستظل أدوات الملفات والمحرر والمعاينة والتصدير متاحة، بينما يعرض المساعد رسالة إعداد واضحة. لا تضف المفتاح إلى متغير يبدأ بـ `NEXT_PUBLIC_` ولا ترفعه إلى GitHub.

## Firebase (اختياري في هذه النسخة)
1. أنشئ Web App من Firebase Console.
2. فعّل Authentication بالمزوّد المطلوب.
3. أنشئ Firestore Database.
4. ضع قيم إعدادات تطبيق الويب في متغيرات `NEXT_PUBLIC_FIREBASE_*` داخل `.env.local`.
5. قبل إضافة حفظ سحابي، طبّق قواعد Firestore التي تقيّد كل مستند بمستخدمه وتختبرها. إعدادات الواجهة وحدها لا تحمي البيانات.

## ملاحظات أمان
- مفتاح AI يُقرأ في Route Handler على الخادم فقط.
- معاينة المشروع داخل iframe مع `sandbox="allow-scripts"` من دون `allow-same-origin`.
- استيراد ZIP يرفض المسارات التي تتضمن `..` ويتجاهل الملفات الكبيرة جدًا.
- لا تشغّل حزمًا أو أوامر بناء من مشاريع غير موثوقة على خادم الإنتاج دون حاوية معزولة وحدود موارد.
- قبل نشر الخدمة لمستخدمين متعددين، أضف مصادقة خادمية وحدود استخدام ومراقبة وتخزينًا سحابيًا بقواعد صلاحيات دقيقة.

## البناء

```bash
npm run build
npm start
```

## النشر
يمكن نشر التطبيق على استضافة تدعم Next.js (مثل منصة تشغيل Node.js). عيّن `OPENAI_API_KEY` و`OPENAI_MODEL` كمتغيرات بيئة سرية من لوحة الاستضافة، ثم نفّذ build. لا ترفع `.env.local` إلى المستودع.
